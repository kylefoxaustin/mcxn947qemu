# PER-INSTANCE COVERAGE MANIFEST -- the CENSUS, not the total.
#
# ⭐ A TOTAL CANNOT SEE A MISSING BLOCK.
#
# This gate used to assert only the TOTAL register count.  That is a control on the
# SIZE of the coverage and NOT ON ITS SHAPE: if the eDMA's 336 registers vanished and
# something else grew by 336, the total would be unchanged and the gate would PASS.
# (91emulator, who lived it -- their blind-block check went green after they REVERTED
# the fix, because one block kept the handful of rows that happened to parse.)
#
# ⭐ AND A PRESENCE CHECK CANNOT SEE A HALF-EMPTY BLOCK.
#
# So this is a CENSUS: every instance, with its COUNT.  (ollama_95_neutron: a ledger of
# SHAPES said nothing when 179 of 180 tensors stopped offloading -- "a control on the
# SET, not on the CENSUS".)
#
# It fails in EVERY direction:
#     an instance MISSING          -> FAIL: it went blind
#     an instance's count DROPPED  -> FAIL: it went half-empty
#     an instance's count GREW     -> FAIL: good news, but DECLARE it
#     a NEW instance appeared      -> FAIL: declare it
#
# Nothing may change silently.  Regenerate with:  tests/mcxn-reset-values/check.py --bless
#
